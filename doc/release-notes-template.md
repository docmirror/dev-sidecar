# 发布说明模板（GitHub Release 正文）

按 v2.3.3 的结构写。workflow 创建的草稿 Release **正文是空的**，发布前必须按本模板补全，否则又会出现格式不一致。

复制下面的骨架，替换占位内容：（注意占位内容按照C语言注释格式，圆括号内容是需要原样保留的）

```markdown

#### 【摘要】

// 一段话概括本版做了什么、解决了什么、有没有需要注意的破坏性变化

#### 【新特性】

// 没有新增功能就删掉这一节

- **功能名称**：做了什么，用户怎么用，有什么边界。

#### 【优化】

- **优化点**：改前是什么体验，改后是什么体验。

#### 【问题修复】

- **修复现象**：用户看到什么错误；原因一句话；现在的行为。

#### 【其他】

- 面向开发者/CI/文档的变更，普通用户可以跳过。
```

- [ ] 未签名时写明「SmartScreen 会提示一次，选仍要运行」

- [ ] `四、Full Changelog` 的版本号已替换
